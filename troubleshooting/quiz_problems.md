# Quiz Feature Troubleshooting

## 1. Problem: Questions in the quiz were not being displayed

- **Cause:**  
  Additional text was being generated by the LLM when generating questions in JSON format.

- **Fix:**  
  Extracted the JSON portion from the raw response, then verified the extracted data by checking if it matched a valid dictionary format.

- **Learning:**  
  LLMs do not always generate precise or clean output. It is essential to extract and validate the required data from their responses.


## 2. Problem: When attempting quiz for 20 questions, only a few were generated

- **Cause:**  
  Generating 20 questions can be resource-intensive for some LLMs, causing delays or incomplete output.

- **Fix:**  
  Modified the prompt to explicitly instruct the LLM to generate all 20 questions when requested.

- **Learning:**  
  LLMs are not always reliable at handling large tasks in one go. Therefore, thorough testing is essential when designing features that depend on LLM outputs.
